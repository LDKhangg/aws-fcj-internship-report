# AWS First Cloud Journey — Internship Report Site

Static documentation site (Hugo) for my **AWS First Cloud Journey** internship program (Sep–Nov 2025): weekly worklogs, project proposal, workshops, events, and self-evaluation. Content is bilingual (English / Vietnamese).

> 🇻🇳 Site báo cáo thực tập chương trình **AWS First Cloud Journey**: worklog theo tuần, proposal, workshop, sự kiện và tự đánh giá. Tóm tắt tiếng Việt ở [cuối trang](#-tóm-tắt-tiếng-việt).

## Content

| Section | What's inside |
|---|---|
| `1-Worklog` | Week-by-week internship worklogs |
| `2-Proposal` | Final project proposal — Electric Vehicle Rental Booking platform on AWS (EC2, S3, RDS, IAM) |
| `4-EventParticipated` | AWS events attended |
| `5-Workshop` | Hands-on AWS workshops completed |
| `6-Self-evaluation` | Program self-assessment |
| `7-Feedback` | Feedback and takeaways |

## Tech

- **Hugo** static site generator with the `hugo-theme-learn` (workshop variant) theme
- Bilingual content (`_index.md` / `_index.vi.md`)
- Deployable to **GitHub Pages**

## Run locally

```bash
hugo server      # http://localhost:1313
```
